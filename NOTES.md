# Netflix Episodes — Lampa plugin

Файлы:

- `netflix_episodes.js` — сам плагин.
- `test_emulator.html` — эмулятор модального окна Lampa для локальной проверки в браузере.

## Что делает

- Подписывается на события `torrent_file` (типы `list_open`, `render`, `list_close`).
- Определяет сериальную раздачу: если у хотя бы одного отрисованного `element` есть `season` и `episode` — список трактуется как сериал.
- Если серий нет (фильм, одиночные файлы) — плагин **ничего не меняет**, оригинальный вертикальный список остаётся.
- Для сериалов:
  - прячет оригинальный `.torrent-files` (DOM остаётся — обработчики и ленивые картинки живы);
  - рисует горизонтальную карусель карточек `.nfx-card` с разделителями сезонов;
  - под каруселью показывает панель с изображением, названием серии, датой, сезоном/номером, размером файла и описанием;
  - фокус карточки обновляет панель и прокручивает полосу;
  - `hover:enter` на карточке **делегируется обратно в оригинальный `.selector`** — запускает `Player.play`, плейлист и историю как в штатной Lampa;
  - `hover:long` делегируется оригиналу (меню «смотреть с начала / выбрать плеер»);
  - `hover:focus` дополнительно триггерится на оригинальном item, чтобы работала lazy-подгрузка изображения.

## Ключевые исправления против предыдущей версии

1. **Реальная форма `params.seasons`.** По исходнику `lampa-source/src/interaction/torrent.js` `params.seasons[season]` — объект `{ episodes: [...] }`, не массив. `findEpisodeMeta` теперь ищет в `.episodes` и поддерживает оба варианта на случай старых данных.
2. **`list_open` приходит с сырыми `items`, а не с DOM.** Удалён мёртвый ветка `items.each`/`data('nfx-element')` — собираем пары только из `render`-событий.
3. **Плагин не задевал фильмы.** Раньше любой список подменялся нашим UI. Теперь решение принимается по `anyEpisodes()`; если за 1.5 сек после `list_open` ни один `element` не содержит `season/episode` — `is_serial=false` и оригинальный интерфейс остаётся.
4. **Жизненный цикл.** Отдельные таймеры для fallback-решения и `scheduleBuild`; `MutationObserver` следит за удалением модалки (если `list_close` не придёт — например, модалка закрыта другим плагином).
5. **`updateDetail` безопаснее.** `metaBits` собирается `<span>`-ами, корректно склеивается; `meta.runtime` выводится; у `esc` для всех полей.
6. **`resetForOpen` всегда переинициализирует `serial_decided`/`is_serial`** — повторное открытие не тащит старое состояние.
7. **Клик/наведение мышью** на карточки всё ещё работает (для проверки на ПК), но на TV путь — `hover:focus`/`hover:enter` через `Lampa.Controller`.

## Что сохранено визуально

- Карусель `.nfx-episodes__strip` с flex-gap'ом 0.9em.
- Карточка `.nfx-card` 11.5em шириной, радиус 0.5em, focus = белая рамка + scale(1.05).
- Детал-панель `.nfx-detail`: изображение 16:9 шириной 22em, крупный заголовок, мета-строка, описание.
- Тёмная тема по умолчанию; медиа-запрос для мобильной ширины.

## Как проверить локально

1. Открыть `test_emulator.html` в браузере.
2. Нажать **«Открыть «Сериал»»** — появится карусель, по стрелкам ←/→ двигается фокус, Enter — «воспроизведение» (выводится в HUD внизу).
3. **«Открыть «Фильм»»** — должна остаться стандартная вертикальная разметка, нашего UI нет.
4. **«Открыть «Смешанная раздача»»** — сериальные файлы в карусели, srt/jpg попадают в группу «Прочее» в конце полосы.
5. **«Long на фокусе»** — должен вызвать `hover:long` на текущей карточке (в эмуляторе печатается в HUD).
6. **«Закрыть»** — модалка уходит, второе открытие снова строит карусель без дублей.

## Установка в Lampa (Tizen / любая)

Вариант А — локальный HTTP-сервер:

```powershell
cd F:\popa
# любой статический сервер, например:
npx serve -l 8080 .
```

В Lampa: *Настройки → Расширения → Добавить плагин* → `http://<IP-компа>:8080/netflix_episodes.js`.

Вариант Б — через GitHub Gist / свой хостинг (тот же URL-приём).

## Что проверено и что осталось на реальном ТВ

Проверено в эмуляторе:

- карусель строится по `render`-событиям;
- фильмы не подменяются;
- делегирование `hover:enter`/`hover:long`/`hover:focus` на оригинальный item;
- закрытие и повторное открытие без утечек.

Требует проверки на Samsung Tizen с реальным Lampa + TorrServer:

- точные имена CSS-классов `.modal`, `.torrent-files` в текущей сборке Lampa;
- поведение `Lampa.Controller.collectionSet/Focus` при уже открытой модалке (может понадобиться переключение на активный layer);
- `Lampa.Api.img()` — URL префикс для `still_path` может отличаться (проверить на реальной карточке);
- автофокус на первой карточке после открытия;
- `hover:back` — на Tizen может требоваться специальная обработка возврата пульта;
- стабильность при больших раздачах (>50 серий) — может понадобиться виртуализация карусели.

## Известные ограничения

- `params.seasons` индексируется числовым сезоном; если TorrServer вернёт `season=0` для спецвыпусков — они попадут в карусель под «Сезон 0».
- «Просмотрено» (`nfx-card--watched`) смотрит на `element.viewed_percent`/`viewed_time` — фактические поля в Lampa могут отличаться; если в UI не появляется приглушение, нужно будет посмотреть `params.viewed`.
